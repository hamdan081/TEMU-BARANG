Prosedur Git yang diminta:
1. Jalankan `git status --short` dan `git branch --show-current`; jangan lanjut jika ada perubahan tak terkait yang berisiko tertimpa.

3. Jalankan `npm install` (dengan internet) untuk menyinkronkan lockfile, lalu cek instalasi dan sintaks. Uji aplikasi pada ponsel Expo SDK 57 bila tersedia.
4. Review `git diff --check` dan `git diff`. Pastikan `.env`, `server/data/`, `.git`, dan `node_modules/` tidak ikut ter-commit.
5. Stage hanya perubahan Task 01: `git add App.js components/BottomNav.js components/sensors/SensorScreen.js hooks/useAccelerometer.js package.json package-lock.json app.json docs/week7/task1.md`.
6. Jalankan `git commit -m "feat(week7-task1): connect TemuKampus to accelerometer"`.
7. Pastikan remote `origin` mengarah ke repository saya; jalankan `git push -u origin HEAD` tanpa force-push.
8. Laporkan SHA commit, nama branch, dan hasil push. Jika belum login GitHub atau push gagal, jangan mengklaim berhasil.
